# فروشگاه آنلاین و اپ مدیریت

پروژهٔ شروع شامل سایت مشتری، API جاوا و اپ دسکتاپ JavaFX برای مدیریت محصولات است. در اجرای محلی با Maven، داده‌ها در فایل H2 محلی ذخیره می‌شوند؛ فایل‌های دیتابیس و محصولات محلی در مخزن ثبت نمی‌شوند. API برای PostgreSQL نیز قابل تنظیم است.

## اجرا

1. در ریشهٔ پروژه اجرا کنید: `mvn -pl backend spring-boot:run`
2. سایت مشتری: `http://localhost:8080`
3. در ترمینال دیگری اجرا کنید: `mvn -pl admin-app javafx:run`

اپ مدیریت با API محلی ارتباط می‌گیرد. برای تغییر نشانی API، متغیر محیطی `STORE_API` را تنظیم کنید.

## اتصال به Supabase/PostgreSQL

متغیرهای `DB_URL`، `DB_USER` و `DB_PASSWORD` را از بخش اتصال پروژهٔ Supabase تنظیم کنید. نشانی JDBC قالب `jdbc:postgresql://HOST:5432/postgres?sslmode=require` دارد. سپس backend را با همان فرمان بالا اجرا کنید. رمز و کلیدهای دسترسی را داخل کد یا مخزن قرار ندهید.

## وضعیت فعلی

نسخهٔ شروع برای نمایش کالا و مدیریت پایهٔ کالاها (افزودن، ویرایش، حذف) است. تغییر کالاها با کلید مدیر در متغیر محیطی `STORE_ADMIN_KEY` محافظت می‌شود؛ در اجرای محلی مقدار پیش‌فرض `local-dev-key` است. سبد خرید فعلاً فقط شمارندهٔ نمایشی دارد. ثبت سفارش، پرداخت و سامانهٔ کامل حساب کاربری/ورود هنوز اضافه نشده‌اند. برای انتشار عمومی، مراحل فایل `DEPLOY.md` را دنبال کن.
